# ============================================================
# Redmi AX6 / IPQ807x —— 主线源码专用配置
#
# 【重要：分区表】
# 本机实测运行中的可用固件为「Redmi AX6 (stock layout)」，
# 即原厂分区表（U-Boot 带 web 恢复页，但仍保留 stock 布局）。
# 因此必须编译 -stock 变体（DTS: ipq8071-ax6-stock.dts）。
#
# 此前多次编译的 redmi_ax6（扩展分区表，DTS: ipq8071-ax6.dts）刷入后
# 表现为：蓝灯常亮、链路协商 1Gbps、但 br-lan 无端口、拿不到 DHCP、
# 静态 IP 也 ping 不通——根因是布局/DTS 不匹配。
#
# 源码选用说明：fork（VIKINGYFY/immortalwrt）重写了 qca_edma / qca_ppe
# 与 DSA tagger；本机验证可用的是 immortalwrt 主线（与 kwrt 同源）。
#
# 机型列表必须显式排他：GENERAL.txt 里 MULTI_PROFILE=y，
# 未列出的机型会按默认值进入构建，导致产物混乱。
# ============================================================
