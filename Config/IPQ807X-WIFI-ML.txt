# ============================================================
# Redmi AX6 / IPQ807x —— 主线源码专用配置
#
# 背景：VIKINGYFY/immortalwrt（owrt 分支）重写了 qca_edma / qca_ppe 与 DSA
# tagger，其 ipq807x 有线数据面在 AX6 上不通（链路能协商 1Gbps，
# br-lan 已内置写死 lan1~lan3、静态也 ping 不通，配置层已排除）。
# 因此 AX6 改用 immortalwrt/immortalwrt 主线源码（与 kwrt 同源，实测可用），
# ZN-M2 继续使用 fork（NSS/PPE 定制）。
#
# 机型列表必须显式排他：GENERAL.txt 里 MULTI_PROFILE=y，
# 未列出的机型会按默认值进入构建，导致产物混乱。
# ============================================================
