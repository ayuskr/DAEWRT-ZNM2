# ============================================================
# ZN-M2 / 京东云亚瑟 AX1800 Pro（IPQ6000，ipq60xx）—— NSS 版
#
# 与 IPQ60XX-NOWIFI 唯一区别：显式带上 kmod-nss-wifi-drv + nss-firmware。
# nss-wifi-drv 依赖为 @(ipq807x||ipq60xx) +nss-firmware +kmod-nft-bridge，
# 与 ath11k 无关，因此关掉 WiFi 软件栈也能跑 NSS。
# 模块不自动加载，由 /etc/init.d/nss-wifi 启动，nss-wifi.general.offload 默认 1。
# ============================================================
